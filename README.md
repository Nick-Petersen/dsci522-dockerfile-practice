# DSCI 522 Dockerfile Practice

This repository contains my individual assignment for DSCI 522, practicing how to build a Docker image using a Python project managed with uv and publish it to Docker Hub using GitHub Actions.

## Dependencies

- Python 3.14
- cowsay
- numpy

## Project Setup

Install the project dependencies using:

```bash
uv sync
```
